## 技术摘要

本项目面向零功率反应堆相关研究中 He-3 正比计数管信号的软件仿真需求，建设一套从真实中子到达事件、
参数化沉积能量、前置放大器脉冲、连续堆积波形，到 ADC、触发、死时间和数据集输出的可复现计算平台。
系统以死时间之前的真实计数率、采样率和观察时间为主要工况输入，当前支持 `10～10^7 cps`、
`100～250 MS/s`，覆盖从稀疏脉冲到强堆积波形的六个数量级计数率范围。

截至本稿形成时，Phase 0～3 已完成自动验收和用户人工审核；Phase 3.5 本地 Web 集成已完成自动验收，
正在等待人工审核。系统已经实现两种精确泊松抽样算法、参数化 He-3 能谱、能量到幅值映射、峰值归一化
双指数脉冲、参考与递推连续波形后端、噪声与基线、模拟裁剪与 ADC、正负极性触发、延长型/非延长型
死时间、多尺度流式 HDF5 数据集以及本地交互式波形生成界面。当前全量回归测试为 **137 项通过、
0 项失败、0 项跳过**，并完成 **13 个标准计数率点**的死时间统计验证。

当前成果应被理解为“物理与软件链路已闭合的合成基线”，而不是已标定的真实探测器数字孪生。
能谱、增益、时间常数、噪声、量程和 ADC 参数仍标记为 `synthetic_demo`。项目下一阶段将使用孤立脉冲和
多个已知计数率下的示波器波形完成标定，再研究条件事件生成模型与受物理约束的波形残差模型，最终形成
统计正确、可解释、可复现且能够逐步逼近真实前放输出的信号生成与验证平台。

**关键词：** He-3 中子探测；齐次泊松过程；脉冲堆积；连续波形；死时间；HDF5；可复现仿真

## 项目要解决的是“数据稀缺、强堆积和模型可信度”三重问题

He-3 探测系统在不同计数率下呈现显著不同的波形形态：低计数率时事件近似孤立，高计数率时多个脉冲在
前置放大器响应时间内重叠，触发、饱和和死时间进一步改变最终可观测计数。若直接用死时间删除事件，或只
模拟孤立脉冲，就无法复现连续堆积波形，也无法正确评价触发算法和采集链路。

与此同时，当前尚缺少足量、覆盖多计数率工况并带有可靠标注的真实示波器数据。项目因此采用“物理基线
先行、实测标定居中、神经网络最后进入”的路线：先建立数学可验证、数据可追溯的合成系统，再利用实测数据
校准模型，最后只让神经网络学习物理模型不能解释的部分。该路线既降低早期数据不足带来的开发阻塞，也避免
以视觉相似度代替物理正确性。

项目服务的核心场景包括：高计数率堆积与饱和研究、触发和死时间算法验证、采集系统参数研究、数据格式与
分析流程开发，以及后续机器学习模型的受控训练数据生成。当前软件不承担真实设备安全判断或在线控制。

## 当前成果已经形成从工况输入到数据产物的完整闭环

当前版本已经打通如下链路：

`工况与配置 → 泊松真值事件 → He-3 参数化能谱 → 幅值与脉冲参数 → 连续波形叠加 → 基线与噪声 →`
`裁剪前诊断电压 → 软件量程裁剪 → ADC → 触发与死时间 → HDF5/CSV/PNG/JSON/YAML`。

其中，真实事件层、模拟电子学层和观测层被严格分离。所有真实事件都保存在真值表中并参与连续波形叠加；
死时间只影响观测候选的接受状态，不会从真值事件或连续波形中删除事件。这一数据语义使强堆积条件下的
“发生了多少事件”“波形由哪些事件构成”“最终记录了多少触发”可以分别追踪。

本地 Web 界面允许用户输入真实计数率、采样率、观察时间和随机种子，自动显示输入范围、预期事件数、
采样点数、采样间隔与原始数组规模，并生成完整 HDF5、两列 CSV、波形 PNG、实际配置和采样信息 JSON。
界面后端复用已经验证的物理 API，不另建第二套生成逻辑。

在 `10^7 cps`、`100 MS/s`、`15 ms`、seed `20260303` 的复核任务中，软件生成了 **149843 个真值事件**
和 **1500001 个采样点**。演示配置的裁剪后 ADC 输入达到 **100% 饱和**，但新数据结构同时保存裁剪前诊断
电压，仍可观察约 `7～10 V` 的连续堆积变化。这一结果说明系统能够区分“波形生成失败”和“配置量程不足”。

## 方法设计以可解释物理模型和可回归实现为核心

### 真值事件与能谱

当前非相关热中子到达采用恒定计数率齐次泊松过程。在时间窗 `T` 内，事件数满足
`N(T) ~ Poisson(lambda × T)`，相邻间隔服从参数为 `lambda` 的指数分布。固定窗口主路径采用
“泊松计数 + 排序均匀时刻”，同时保留累积指数间隔算法用于交叉验证和流式扩展。

沉积能谱由 764 keV 全能峰、质子壁效应、氚壁效应和可选双壁效应组成。当前实现采用可配置混合分布：
全能峰使用正值截断高斯，壁效应使用定义域受限的 Beta 分布。能量通过线性关系映射为正的目标峰值幅度，
脉冲极性独立保存。所有形状参数和增益参数仍是合成演示值。

### 连续脉冲、堆积与数字化

单事件使用峰值归一化双指数响应：`g(s)=exp(-s/tau_d)-exp(-s/tau_r)`，其中
`tau_d > tau_r > 0`。实现不仅保证连续模型归一化，还校正事件相对采样网格的分数相位，使孤立事件的
离散峰值对应目标 `A_peak`。

连续电压由全部事件脉冲、基线和噪声求和得到。软件保留逐事件 `direct_sparse` 参考实现，并提供
固定时间常数的 `recursive_fixed_tau` 递推实现；后者维持跨块指数状态，使内存受块大小和显式上限约束，
而不是随整个观察时间无限增长。参考实现与优化实现之间有一致性回归测试。

波形随后经过模拟量程裁剪、ADC 偏置与量化，并产生逐采样点饱和标记。当前同时保存裁剪前诊断电压和
裁剪后 ADC 输入电压：前者用于分析强堆积形态，后者用于保持数字化链路的真实软件语义。这里的简单裁剪
不代表真实前放的非线性饱和恢复。

### 触发、死时间与多尺度数据集

触发器支持正/负极性阈值、滞回、最小保持时间和跨块状态。死时间支持 `none`、非延长型和延长型模式，
并同时提供事件级理想模型和波形触发模型。触发与真值事件通过多对多关联表连接，以适应一个触发对应多个
堆积事件的情况。

为避免在低计数率下为获得足够事件而渲染极长的满采样波形，系统区分事件统计视界、有限连续波形区和
事件中心窗口。事件与波形均可分块写入压缩 HDF5；连续区外的真值事件仍保留，但明确标记为未渲染样本。

## 验证结果支持当前合成基线的工程可用性

当前验证覆盖数学、统计、数值、数据格式、可复现性、性能边界和界面集成：

- 两种泊松算法通过事件数均值、Fano 因子、间隔分布和分布一致性检查；
- 参数化能谱通过权重、定义域和峰位测试，不产生负能量或负幅值；
- 单脉冲峰值、时间平移、正负极性、双事件线性叠加均有数值测试；
- 参考渲染器、递推渲染器以及分块/整段边界保持一致；
- 噪声、基线、裁剪、ADC 和随机种子行为可复现；
- 延长型与非延长型死时间在 13 个标准计数率点上与解析关系进行统计比较；
- 真值事件、观测事件、触发窗口和关联表可以从 HDF5 回读与追溯；
- Web 页面和后端可以在无浏览器、无网络条件下自动测试。

最新验收结果为：Ruff 格式与静态检查通过，mypy 对 44 个源文件检查无问题，pytest **137 项全部通过**，
`he3sim web --help` 与 `git diff --check` 通过。Phase 3 的 13 点扫描在 `10^7 cps` 时，非延长型死时间的
模拟/理论观测率约为 `4.984e6/5.000e6 cps`，延长型约为 `3.664e6/3.679e6 cps`。

这些结果证明当前软件基线在既定数学假设下可运行、可测试和可复现，但不能证明其已经匹配某一台真实
He-3 探测器或前置放大器。

## 项目创新集中在可信分层、强堆积处理和可追溯工程化

1. **三层事件语义。** 把真实事件、连续电子学波形和观测事件分开保存，使死时间与堆积的物理含义不被混淆。
2. **精确基线与优化实现并存。** 已知泊松过程不由神经网络替代；连续波形同时保留参考后端和高效递推后端。
3. **面向六个数量级计数率的流式架构。** 事件、波形、触发状态和随机状态跨块连续，并由显式上限控制内存。
4. **裁剪前后双通道诊断。** 同时呈现合成波形形态和 ADC 量程结果，避免把高计数率压平误判为绘图失败。
5. **科研数据全链路可追溯。** 配置、单位、代码版本、随机种子、参数状态、配置哈希和事件关联都写入产物。
6. **从核心 API 到本地交互界面的同源实现。** Web 只编排既有物理模块，降低界面与批处理结果漂移的风险。

## 当前边界决定了报告只能主张“合成基线完成”

当前模型仅覆盖恒定计数率、非相关热中子的齐次泊松到达。He-3 能谱、能量到幅值增益、双指数时间常数、
噪声、模拟量程、ADC 和触发阈值尚未由真实设备数据标定。系统也尚未包含空间电荷、气体增益随计数率变化、
前放非线性恢复和真实饱和恢复，因此不能用当前电压值推断某一真实装置的定量响应。

Phase 3.5 仍处于自动验收通过、等待人工审核状态；Phase 4 因缺少真实示波器数据而保持阻塞。网络 A 与
网络 C 尚未实现，DT5800/DT5790 控制、实时采集、远程服务和在线安全应用也不属于当前成果。

比赛展示时应把当前波形明确标注为 `synthetic_demo`，把“统计正确、数据可追溯、软件闭环和高计数率
可生成”作为现阶段成果，把“接近真实设备波形”作为获得标定数据后的目标。

## 最终目标是形成实测约束下的可解释信号生成与评价平台

项目最终希望回答：给定真实计数率、采样率、时间窗和探测器/电子学配置，能否生成统计正确、可解释、
可复现，并逐步接近实测前放输出的连续脉冲波形？为实现这一目标，后续路线为：

1. **完成 Phase 3.5 人工审核。** 固化本地 Web 操作、输入边界、产物和高计数率显示体验。
2. **Phase 4 实测标定。** 导入孤立脉冲及多个已知计数率下的示波器波形，完成单位识别、基线与噪声分析、
   脉冲检测对齐、双指数拟合、联合参数分布和质量控制，形成 `provisional`/`validated` 配置。
3. **接入更真实的能量沉积分布。** 在数据条件具备时导入 MCNP 事件列表或能谱直方图，并与参数化能谱比较。
4. **Phase 5 条件事件模型 A。** 作为研究对照学习非理想或相关事件 marks；若不能优于精确泊松基线，保持关闭。
5. **Phase 6 物理残差模型 C。** 以实测波形减去同事件参数物理重建波形作为残差目标，只修正基线、频谱和
   细微形状差异，不允许改变事件到达率或无故新增、删除事件。
6. **建立三链路评价。** 比较纯物理、物理事件加残差、网络事件加物理合成加残差，在留出采集 run 和留出
   计数率上评价计数统计、幅值与时间参数、功率谱密度、波形相似度、速度和资源消耗。

完成上述路线后，系统可成为探测信号算法研究、采集链路设计、合成数据生成和实测对照分析的统一平台；
是否接入真实硬件控制仍需在离线软件与标定链路通过后单独评估。

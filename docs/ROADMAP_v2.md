## 1. 核心思想：三级验证阶梯（Three-Tier Validation Ladder）

新要素让课题从"纯软件孪生"升级为一个层层去风险的验证体系。每一级用"已知真值"验证下一级的假设：

```
Tier 1  软件孪生（in-silico）
        相关中子生成 → 波形 → 噪声反演；用解析靶自证正确（复原设定的已知 α）
        判据：纯数学闭环，不依赖任何硬件或反应堆
                        │  验证：生成/反演算法本身对不对
                        ▼
Tier 2  硬件在环（DT5800，已知真值 / 无反应堆）
        把已知的事件结构经"真实电子学链"（DT5800 → 真实数字化仪）走一遍
        验证：脉冲形状、噪声、基线漂移、死时间、堆积、双探测器互协方差在真实电子学下是否仍成立
        判据：DT5800 的输入是已知的，因此偏差可归因
                        │  验证：软件孪生的"探测器+电子学"假设在真实硬件上成立
                        ▼
Tier 3  零功率反应堆（真实裂变链）
        真实 He-3 探测器 + 真实中子噪声；孪生预测、实验确认
        判据：在多个已知反应性状态上，孪生反演的 α 与实验一致；连续信号法在真实 He-3 数据上首次系统验证
```

这条阶梯本身就是论文/答辩的主叙事：**软件（算法对）→ 硬件仿真（电子学对）→ 反应堆（物理对）**。它也解释了为什么两个新要素不是附属功能，而是把课题的可信度整体拔高了一个量级。

## 4. 为什么"先做纯瞬发"是正确的第一步

- **无需稳态预热**：纯瞬发的次临界源驱动系统**立即处于稳态**（没有缓发先驱核的长弛豫），Phase A 不必处理 burn-in / 平衡浓度预置，实现和验证都最简。
- **验证靶最干净**：瞬发-only 的 Feynman/Rossi 曲线是**单指数**（只有 prompt 项，无缓发平台），α 复原判据一目了然。
- **符合 Boros 2026 的做法**：把恒定外源当作"缓发中子在平衡时的等效常源"，系统在稳态等价于临界系统——这正是零功率噪声实验的标准设置。
- 缓发中子作为 Phase A2 增量加入，不影响主结构。

## 5. 物理引擎规格（Phase A 纯瞬发）

### 5.1 一速点模型 + 外源

每个中子以竞争性指数时钟发生三类反应：

| 反应 | 每中子率 | 效果 |
|---|---|---|
| 裂变 | λ_f | 移除入射中子，产生 ν 个瞬发中子（ν~pν，均值 ν̄） |
| 俘获/吸收(含泄漏) | λ_c | 移除中子 |
| 探测 | λ_d | **记录探测时刻**（He-3 (n,p)），移除中子 |

总移除率 `λ_t = λ_f + λ_c + λ_d`。外源强度 S（泊松）。

### 5.2 参数映射（纯瞬发，可自洽推导，务必做进配置校验）

用户设定物理量 `(k_eff, α, ε, ν̄, pν, S)`，代码**反解**出率：

```
λ_t = α / (1 − k_eff)              # 由 α = λ_t(1 − k) 反解（纯瞬发）
λ_f = k_eff · λ_t / ν̄
λ_d = ε · λ_t
λ_c = λ_t − λ_f − λ_d = λ_t · (1 − k_eff/ν̄ − ε)     # 需 ≥ 0，否则报错
```

派生量（作为 `derived`，并在代码里断言一致）：

```
k_eff = ν̄·λ_f / λ_t
ρ     = (k_eff − 1) / k_eff
ε     = λ_d / λ_t
α     = λ_t − ν̄·λ_f = λ_t·(1 − k_eff)     # prompt 中子衰减常数（核心）
Λ     ≈ 1 / (ν̄·λ_f)                        # 代次时间尺度（随定义差常数，文档标注）
D_ν   = ⟨ν(ν−1)⟩ / ⟨ν⟩²                    # Diven 因子（控制关联幅度）
```

**一阶解析靶（Phase A 必过）**：稳态平均探测率
```
R_d = S · ε / (1 − k_eff)          # k→0 退化为 S·ε；k→1 发散（源驱动临界）
```

### 5.3 算法：逐链源驱动（纯瞬发，可并行）

外源中子独立 → 每个源中子的裂变链独立模拟再叠加；次临界下链必然灭绝、天然终止、无需缓发处理。

```
输入: S, duration D, (λ_f, λ_c, λ_d), pν
1. 采样源中子时刻 {t0_j} ~ 齐次泊松(S) on [0,D]      # 复用现有泊松采样器
2. 对每个源中子 j（可多进程/向量化批处理）:
     stack = [t0_j]
     while stack:
         t = stack.pop()
         dt ~ Exp(λ_t);  reaction_time = t + dt
         按 (λ_f:λ_c:λ_d) 抽反应:
             capture   → 中子消失
             detection → 记录探测时刻 reaction_time（含 chain_id, generation）; 中子消失
             fission   → 抽 ν~pν; 将 ν 个瞬发子代 push(reaction_time)  # 纯瞬发：全部立即入栈
3. 汇总所有链探测时刻, 排序 → 探测事件时间数组（喂下游）
```

近临界 k→1 时链变长 → **备选**：布居跟踪 Gillespie + 显式布居上限（承既有安全护栏风格）。纯瞬发本轮以次临界为主，Gillespie 可留到 A2。

### 5.4 与现有代码集成（零摩擦）

- 新增 `physics/chains.py`（`BranchingChainGenerator` 实现 `EventArrivalGenerator`）、`physics/source_model.py`（映射+校验）。
- 新增配置段 `source_model`（`k_eff`/`reactivity`、`alpha`、`detection_efficiency`、`nu_bar`、`nu_pmf`、`source_rate_cps`；派生率与 α/Λ/D_ν）。全部 `synthetic_demo`。
- `events.py` 中 `arrival_generator_for(...)` 是唯一替换点；保留 `poisson` 为默认基线与回归对照。
- `TRUE_EVENT_DTYPE`：复用 `pileup_group_id` 存 `chain_id`，或新增 `chain_id/generation` 字段（旧数据填 -1，向后兼容）。

## 6. 噪声分析与验证（Phase B）

三估计器（作用在触发/观测事件上）：

- **Rossi-α**：时间差直方图，拟合 `p(τ) = B + A·e^{−α|τ|}`。
- **Feynman-α（VTM）**：多门宽 T，`Y(T) = Var(C)/⟨C⟩ − 1 = Y∞·[1 − (1−e^{−αT})/(αT)]`（纯瞬发 = 单指数，无缓发平台）。
- **PSD（Cohn-α）**：计数序列 FFT，拟合 `F(ω) = C·[1 + Y∞·α²/(α²+ω²)]`。

前因子 `Y∞ ∝ ε·D_ν·(k/(1−k))²` 量级（精确系数见 Pázsit–Pál Ch.3），**但主判据是"复原设定的已知 α"**：

```
|α_hat − α_true|/α_true < 容限（如 5%），且 Rossi/Feynman/PSD 三法互相一致。
```

统计严谨性：按 Endo & Yamamoto (2019) 用 bootstrap / 解析误差传播处理 bin 间相关，报告可信不确定度。

死时间/堆积研究：扫描 (真计数率 × α) 网格，量化偏置（非仅损失），复现 Hazama(2003) 修正，画出脉冲计数法可用上限——**这条上限正是 Phase C 要打破的对象**。（真实电子学的死时间行为在 Phase HIL 用 DT5800 标定。）

## 7. DT5800 硬件在环（Phase HIL，Tier 2）—— 详见 `docs/DT5800_HIL_integration.md`

要点（此处只给定位，细节在专文）：

- **DT5800 是"蒙特卡洛的硬件实现"**：可编程脉冲形状/能谱/时间分布/噪声/基线漂移；DT5800D 双通道支持事件关联；任意波形每通道 1M 点 RAM；可从示波器/数字化仪导入形状与能谱。
- **三档使用**（按能力递进）：
  1. **电子学链 + 脉冲模型验证（必成）**：DT5800 用双指数形状 + He-3 能谱 + 噪声 → 经真实数字化仪采集 → 比对软件孪生的边缘统计（脉冲形状、PHS、噪声、上升/下降/电荷）。给孪生的"探测器+电子学"层一个硬件真值。
  2. **死时间/堆积标定（必成）**：扫描 DT5800 计数率 → 观测真实 DAQ + 分析流水线的死时间/堆积行为 → 标定孪生死时间模型，喂回 Phase B。
  3. **双探测器互协方差 + 相关注入（能力依赖，高价值）**：用 DT5800D 双通道关联输出，用**已知注入的关联**验证 Phase C 的 CCF/CTM 估计器与两通道时间同步；若单元支持 (energy,time) 序列/任意波形注入足够深度，则注入 Phase A 生成的**相关事件序列**，在真实电子学上做端到端已知-α 验证。
- **约束（写进设计，先探测能力）**：任意波形 1M 点/通道 ≈ 4–10 ms@100–250MS/s（长连续记录需分段或用 emulation 模式）；堆积内存有限（高速率下 He-3 宽脉冲的可达率受限）；emulation 模式生成的是**其自身随机序列**（匹配你设的分布，但时间是它自己的泊松），不等于你的精确事件表——注入精确相关序列需序列/任意波形模式。
- **工具形态**：厂商无关的导出器（把孪生事件/波形导成 DT5800 可载格式）+ 导入器（把采集回来的波形按 profile 解析）+ 比对报告；**软件侧全部可用合成 fixture 开发与测试，不接实体设备也能通过 CI**。

## 8. 连续信号噪声分析（Phase C，He-3 前沿）—— 论文核心

- **前沿定位**：连续信号噪声法 2015 后成熟、2026（Boros 等 arXiv:2606.10950）才做完可行性实证，用的是**裂变室**，并明确把 **He-3 探测器列为未来工作**。你已能端到端生成 He-3 连续波形 → "He-3 连续信号噪声法的数字孪生验证"是有出处、尚无人系统做过的题目。
- **三件套**（直接作用在你已有的连续波形上）：
  1. 连续 ACF/VTM，含脉冲衰减项：`ACF(θ)=φe^{−α|θ|}+ψ₁e^{−α_e|θ|}+ψ₂|θ|e^{−α_e|θ|}`，`VTM(T)=Φf₁(αT)+Ψ₁f₁(α_eT)+Ψ₂f₂(α_eT)`，`f₁(x)=1−(1−e^{−x})/x`，`f₂(x)=1+e^{−x}−2(1−e^{−x})/x`。α_e 对应你的 `tau_d`。
  2. 平均脉冲去卷积（逆傅里叶 + Wiener）：`d=F⁻¹{F{c}·W}`，`W=F*{f}/(|F{f}|²+γ·NSR)`；扫描 γ–NSR 稳定域（仿真独有优势）。
  3. 双探测器互协方差 CCF/CTM：模拟两探测器观测同一中子场（同链关联共享、自项/电子噪声不共享），自动消掉脉冲形状自项。
- **头条结果**：在孪生里扫描 (真计数率 × α)，给出三条可用边界——脉冲计数 / 连续信号 / 去卷积；证明脉冲计数崩溃的高速率、高 α 区连续信号仍可复原 α，把 Boros 2026 的裂变室结论**首次系统扩展到 He-3**。
- **He-3 特殊性（真问题，别当裂变室复制品）**：He-3 是正比计数器、脉冲更大更慢（α_e 与系统 α 分离度、去卷积难度不同）；有**壁效应**（能谱已建模），幅值分布 w(η) 非平凡——"脉冲=形状×随机幅值"假设在壁效应下是否够好，是可量化的研究问题；连续/Campbelling 经典用于裂变室高通量，He-3 经典用脉冲模式，故"能否/在何工况适用于 He-3"本身是开放问题。**负结果亦是结果**。

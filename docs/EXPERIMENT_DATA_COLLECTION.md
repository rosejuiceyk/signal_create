# 零功率装置实测数据采集规范

> 目的：为 Tier 3（反应堆验证）与 Phase C（真实 He-3 连续信号）规定**采集什么、怎么采、必须记录什么元数据**。
> 教训：既有 DT5790 数据因"相邻点重复、下降沿截断、每计数率仅一个 run、能量仅 ADC 道未标定 keV、采样轴未确认"而无法用于严格评价。**本规范的强制字段就是为了让数据一次采对。**
> 注意：本文是**给实验/人工的采集清单**，不是 Codex 编码任务。Codex 侧对应的是"未来数据接入阶段"（复活 Phase 4 思路），它会按本文定义的 schema 建导入/QC 流水线。

---

## 0. 优先级图例

- 🔴 **必须**：缺了整条主线无法验证。
- 🟡 **应该**：显著提升质量/可信度。
- 🟢 **加分**：锦上添花。

## 1. 探测器与电子学表征（每个探测器各做一次）

### 1.1 静态参数（填表即可）🔴
- He-3 分压、总填充气体与配比、猝灭气体；管径、活性长度、管壁材料。
- 工作高压 HV 设定值；**HV 坪曲线**（计数率 vs HV，🟡，用于确认工作点）。
- 前放型号、增益、成形/时间常数；各段电缆长度与类型（影响频率传递与噪声）。
- 数字化仪/采集卡型号、通道、输入阻抗。

### 1.2 孤立单脉冲（脉冲模型标定的关键输入）🔴
- 在**极低计数率**（堆积可忽略）下采集**大量**孤立单脉冲（目标 ≥ 数千个）。
- 采样率尽量高（≥ 250 MS/s 更好；至少落在项目范围 100–250 MS/s），单脉冲窗口要**完整覆盖上升沿 + 完整下降沿到基线**（DT5790 数据的下降沿截断绝不能再犯）。
- 用途：拟合平均脉冲形状 f(t) → 得到 `tau_r, tau_d`（即 α_e）；构建幅值分布 w(η)；统计上升/下降时间、电荷。
- 输出：平均脉冲形状文件 + 幅值分布直方图 + 单脉冲原始波形集合。

### 1.3 脉冲高度谱 / 能谱标定（PHS）🔴
- 用反应堆场或标定源采集脉冲高度谱（MCA 或离线从波形提取峰值/电荷）。
- 用途：标定 He-3 沉积能谱模型——全能峰（≈764 keV）在 ADC 道/电压上的位置、质子壁/氚壁连续谱形状、阈值。
- **必须给出 ADC 道 ↔ keV 的标定关系**（DT5790 数据缺此项）。至少记录用于标定的参考点（如全能峰道址）。

### 1.4 噪声与本底基线 🟡
- HV 关闭 / 探测器断开时采一段，得到电子学噪声底 + 工频纹波（50/60 Hz 及谐波）。
- 反应堆关闭（或源移出）时采一段本底。
- 用途：噪声模型标定；识别 DAQ 频率传递伪迹（Boros 论文发现连续采集链存在 V 形带阻伪迹，务必检查你的链是否也有）。

## 2. 噪声分析主数据（核心科学）

> 对**每一个反应堆状态**，尽量同时得到"连续波形"与"时间戳脉冲表"两种记录，便于连续信号法与脉冲计数法直接对比。

### 2.1 每个状态要采的东西
- 🔴 **连续原始波形**（未成形的原始电压），高采样率，**长时长**（秒到分钟级；按效率/计数率调整以保证统计）。两个探测器**同步**采集。
- 🟡 **时间戳脉冲表（list mode）**：若 DAQ 支持，同步记录每个脉冲的到达时刻（用于脉冲法 Rossi/Feynman 作交叉验证）。
- 🔴 **状态元数据**：控制棒/安全棒位置、由棒价换算的 k_eff/反应性估计、功率水平；若为源驱动次临界，记录源类型/强度/位置。

### 2.2 状态覆盖设计（决定你能验证什么）
- 🔴 **多个已知反应性的次临界态**（不同棒插入深度）→ 给出一系列**已知 α** 供孪生反演比对。**没有已知-α 的状态就无法验证**。
- 🔴 **多个计数率**（改功率或源强）在固定反应性下 → 覆盖"低速率脉冲计数可用"到"高速率脉冲计数失效"的全区间，用于证明连续信号优势（Phase C 头条图）。
- 🟡 **低功率临界态**作参考。
- 🔴 **两个探测器同时采集**（互协方差/双探测器法必需），并**验证两通道时间同步**（KUCA 教训：两台采集设备时钟漂移会毁掉双探测器评价——优先单一采集时钟/单机多通道；若必须多机，测定并记录时钟偏移与漂移）。
- 🟡 每个计数率**至少两个独立 run**（DT5790 每率仅一个 run，无法做同工况独立 train/val/test 或重复性评估——本次务必 ≥2）。

## 3. 强制元数据 Schema（每个 run 一份，缺一不可）🔴

> 这是让数据"能用"的底线。建议每个 run 配一个 `run_meta.json` 或等价 YAML，字段如下：

```yaml
run_id: <字符串，唯一>
timestamp_utc: <采集时间>
detector:
  channel_map: {ch0: "detA", ch1: "detB"}     # 通道↔探测器
  positions: {detA: "...", detB: "..."}        # 相对堆芯位置/几何
acquisition:
  sample_rate_hz: <数值>                        # 精确采样率（不是标称，是实际）
  n_samples_per_record: <数值>
  time_unit: "s"                               # 明确时间单位
  voltage_unit: "V"                            # 明确电压单位
  adc_bits: <数值>
  full_scale_range_V: <数值>                   # 量程
  input_impedance_ohm: <50 或 high-Z>
  polarity: <"positive"/"negative">           # 脉冲极性
  dc_offset_V: <数值>
  coupling: <"DC"/"AC">
sync:
  method: <"single_clock"/"multi_device">
  measured_offset_s: <数值或 null>            # 多设备时的通道间时钟偏移
  measured_drift: <数值或 null>               # 漂移（如有）
preprocessing_at_acquisition:                  # 采集端若做了任何处理，必须记录
  compression: <"none"/"threshold_gated"/...>  # KUCA 用过阈值门控压缩
  smoothing: <"none"/"moving_average_N">       # KUCA 用过 9/21 点滑动平均
  note: "任何在写盘前施加的处理都要写清楚，否则 PSD/ACF 高频段会被污染且无法复原"
reactor_state:
  rod_positions: {...}
  reactivity_estimate: {value: <数值>, unit: "pcm/¢/k_eff", method: "rod worth"}
  power_level_W: <数值或 null>
  source: {type: "...", strength: "...", position: "...", present: <bool>}
energy_calibration:
  adc_to_keV: {slope: <数值>, intercept: <数值>, ref_points: [...]}   # 不能只存 ADC 道
  full_energy_peak_channel: <数值>
estimated_deadtime_free_rate_cps: <数值>       # 每探测器的死时间前率估计
data_files:
  waveform: <路径>                             # 连续波形
  pulse_list: <路径或 null>                    # 时间戳脉冲表
quality_flags:
  falling_edge_complete: <bool>                # 下降沿是否完整（DT5790 曾截断）
  adjacent_sample_duplication_checked: <bool>  # 是否已排查相邻点重复（DT5790 曾有）
  sample_axis_confirmed: <bool>                # 采样轴/sampleTime 是否与导出数组一致
operator_log: "自由文本：异常、中断、调整等"
```

## 4. 系统性与环境（提升可信度）🟡

- 长 run 期间的温度、HV 稳定性记录。
- 关键频段的 DAQ 频率传递特性刻画（扫频或用 §5 的 DT5800 已知脉冲反推）。
- 本底/源在-源不在对照，用于扣除偶然符合平台。

## 5. DT5800 交叉参照（把两个创新点绑在一起）🔴

- 用**与反应堆 run 完全相同的采集链与设置**，采集 DT5800 生成的**已知脉冲**（同一双指数形状 + He-3 能谱 + 已知计数率）。
- 用途：为"本次实验所用电子学链"提供一个**硬件已知真值**——反应堆数据的电子学部分由此背书，之后连续信号法在真实数据上的偏差才能干净归因于"真实裂变链物理"而非采集链问题。
- 至少覆盖：一个低速率点（对齐脉冲形状/能谱）+ 一个高速率点（对齐死时间/堆积行为）+ 双通道关联点（对齐互协方差与同步）。

## 6. 一页纸采集清单（打印带去现场）

```
[ ] 每探测器静态参数表（几何/HV/前放/电缆）
[ ] 每探测器孤立单脉冲 ≥ 数千（低速率，下降沿完整，高采样率）
[ ] 脉冲高度谱 + ADC↔keV 标定（记录全能峰道址）
[ ] 噪声底（HV off）+ 本底（堆关/源移出）各一段
[ ] 多个已知反应性次临界态（≥3 个不同棒位，记录棒价→反应性）
[ ] 每态多个计数率（低→高，跨越脉冲计数失效点）
[ ] 每计数率 ≥2 个独立 run
[ ] 双探测器同步采集（验证时钟同步/记录偏移）
[ ] 每态：连续波形 + （若可）时间戳脉冲表
[ ] 每 run 一份完整 run_meta（§3 全字段）
[ ] DT5800 已知脉冲经同一采集链：低速率/高速率/双通道关联 各一
[ ] 现场核对三个质量点：下降沿完整 / 无相邻点重复 / 采样轴一致
```

He3Signal Windows 11 便携版
===========================

使用方法
--------
1. 请先完整解压本压缩包，不要直接在压缩包内运行。
2. 双击 He3Signal.exe。
3. 等待默认浏览器自动打开 He-3 脉冲信号模拟界面。
4. 启动控制器会自动最小化到任务栏；恢复并关闭控制器即可停止软件。

数据位置
--------
- 软件会在当前文件夹自动创建 outputs 目录保存结果。
- logs/launcher.log 保存启动日志，只有启动失败时才需要查看。
- 移动或备份时可以复制整个 He3Signal 文件夹。

注意事项
--------
- 支持 Windows 11 64 位，不需要安装 Python、Conda 或项目依赖。
- 软件只监听本机 127.0.0.1，不会作为公网服务开放。
- 本软件当前未购买代码签名证书。首次运行时 Windows SmartScreen 可能显示未知发布者，
  请确认文件来源后选择“更多信息”再选择“仍要运行”。
- 请勿删除 _internal 文件夹或只复制 He3Signal.exe，否则软件无法运行。

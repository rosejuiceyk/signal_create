# Phase 3.5：本地 Web 波形生成界面

- 阶段编号：3.5
- 初始状态：`not_started`
- 前置阶段：Phase 0～3 已通过用户人工审核
- 后续阶段：Phase 4 示波器标定，当前因缺少真实数据而保持阻塞
- 执行原则：本阶段自动验收后停止，等待用户人工审核；不得进入 Phase 4

- `AGENTS.md`

## 本阶段目标

在不改变 Phase 1～3 物理模型和公共数据格式的前提下，提供一个仅绑定本机的
Streamlit Web 界面。用户输入真实计数率、采样率和观察时间，后端生成连续波形、
采样点信息及供人工查看的波形图片。

## 必须实现

1. 本地 Streamlit 表单，填写：
   - 死时间前真实计数率，范围 `10～1e7 cps`；
   - 采样率，范围 `100～250 MS/s`；
   - 固定观察时间；
   - 显式随机种子。
   每个输入项必须在输入框附近显示允许范围；观察时间显示当前工况下的动态范围。
2. 生成前计算并显示预期事件数、采样点数、采样间隔和原始数组字节数估算。
3. 根据当前计数率和采样率计算由采样点上限、预期事件上限共同决定的最大观察时间，
   在观察时间输入框旁显示并作为输入上限；后端仍执行独立校验。
4. 后端复用 `prepare_waveform_simulation`、`write_waveform_hdf5` 和
   `plot_waveform_hdf5`，不得复制一套新的物理生成器。
5. 每次运行创建独立目录并输出：
   - `run_config.yaml`：实际运行配置；
   - `waveform.h5`：裁剪前诊断电压、裁剪后模拟电压、ADC、饱和掩码、真值事件及元数据；
   - `waveform.csv`：完整连续波形的 `time_s,voltage_V` 两列文本表；
   - `waveform.png`：波形总览和事件细节；
   - `sampling_info.json`：输入、采样点数、事件数、单位、seed、参数状态、
     配置哈希、文件大小和相对产物名。
6. 页面不重复显示参数状态警告卡片；参数状态继续保存在 YAML、HDF5 和 JSON 元数据中，
   不得因界面精简而删除可追溯信息。
7. 提供 `he3sim web` 本地启动命令；默认只监听 `127.0.0.1`。
8. 后端和页面均可在 Windows 的 `signal_create` Conda 环境中运行。
9. 波形 PNG 优先显示软件裁剪前的诊断电压，并按可见数据范围自适应纵轴；裁剪后的电压仍作为
   CSV 与 ADC 的输入保留。旧 HDF5 不含裁剪前数据时回退显示裁剪后电压；常量或饱和波形也必须保留可见留白。
10. 高计数率细节图限制事件竖线和饱和散点数量，并显示附近事件数、实际标记数和饱和比例，
    避免标记覆盖波形。
11. 用户手册必须说明从泊松真值事件到波形、ADC、触发/死时间和文件输出的原理，
    并给出物理原型与后端模块的对应关系。

## 测试与验收

- 资源估算的单位和边界测试；
- 四个输入项均显示允许范围，观察时间范围随当前工况动态更新；
- 最大观察时间同时考虑采样点和预期事件两类上限；
- 非法计数率、采样率、时长和超限任务被拒绝；
- 小型固定 seed 任务生成五类产物，CSV 时间/电压与 HDF5 模拟电压逐点一致，
  HDF5 元数据与 JSON 一致；
- 基础配置文件不被修改；
- 相同输入和 seed 生成相同真值事件及波形数组；
- Streamlit 无浏览器测试可加载页面并执行一个小型任务；
- 高计数率、密集事件和完全饱和时仍可从裁剪前诊断数据看到波形变化，事件标记数量有界；
- `he3sim web --help` 可用；
- Ruff、mypy、全量 pytest 和 `git diff --check` 通过。

建议验收命令：

```powershell
conda activate signal_create
python -m ruff format --check .
python -m ruff check .
python -m mypy src
python -m pytest -q
he3sim web --help
git diff --check
```

## 本阶段明确不实现

- Phase 4 的示波器文件导入、参数拟合、标定配置或实测模板；
- 触发、死时间和数据集参数的交互编辑；
- 修改能谱、增益、时间常数、噪声或 ADC 参数的高级标定界面；
- 桌面 GUI、用户账号、权限、数据库、远程多用户或云端托管；
- DT5800/DT5790 控制、实时采集、波形下发或任何硬件通信；
- Phase 5/6 神经网络功能。

# 面向核工程论文的 He-3 探测器随机信号数字孪生技术方案

版本：2026-07-14
适用仓库：`he3_codex_context`
文档性质：研究路线与后续阶段方案；Phase 6S仅为人工干扰工程预演，不代表Phase 4或正式Phase 6
已实现、已标定或已验收

## 1. 技术结论

项目不应把“加入神经网络”本身作为创新点，也不应把当前软件直接称为“核反应堆数字孪生”。
更准确、也更容易形成核工程论文的定位是：

> **面向核反应堆中子监测链路的、可校准且带不确定度的 He-3 探测器通道数字孪生。**

该孪生以死时间前真实计数率和探测器/电子学配置为输入，以真值事件、连续前放波形、ADC、触发与
死时间后的观测量为输出；精确随机过程和可解释电子学模型负责主体响应，轻量神经网络只学习实测与
物理模型之间的有界残差。孪生通过新采集 run 周期性更新参数后验、残差模型和适用域，并输出模型差异
与不确定度，而不是只生成“看起来像真的”波形。

建议把首篇论文的核心问题收敛为：

> 在 `10～1e7 cps` 的宽计数率范围和明显堆积/死时间条件下，物理校准模型能否正确保持事件统计，
> 受物理约束的残差网络能否在按采集 run 严格留出的实测数据上显著改善波形、频谱和触发统计一致性，
> 且这种改善是否具有可量化的不确定度和适用域？

## 2. 当前项目基线与差距

### 2.1 已具备的论文级工程基础

| 能力 | 当前状态 | 可作为论文中的作用 |
|---|---|---|
| 齐次泊松事件到达 | 已实现两种算法并做多计数率验证 | 可解释真值事件基线 |
| 参数化 He-3 沉积能谱 | 已实现 full-energy 与 wall-effect 分量 | 首版能量沉积分布基线 |
| 峰值归一化双指数脉冲 | 已有参考与递推渲染器 | 可解释前放脉冲核 |
| 连续波形、噪声、基线、裁剪和 ADC | 已实现分块有界合成 | 宽计数率波形生成主链 |
| 触发、延长/非延长死时间和事件关联 | 已实现并验证 | 观测层及计数损失模型 |
| HDF5 数据集与本地 Web | 已实现 | 可复现实验和人工审查界面 |
| 网络 A | 历史审核通过后由用户退役 | 只保留审计记录，不再进入活动路线 |
| 代码质量 | 2026-07-14 复验 `145 passed` | 软件可靠性证据，不等于物理有效性 |

网络 A 曾达到合成统计匹配门槛，但只学习 `synthetic_demo` 精确物理分布且吞吐明显低于精确基线。
用户已明确将其退役。历史报告和审核结论继续可追溯，但活动代码、CLI、配置、测试、B5 链路和未来
论文比较均不再保留。exact Poisson + parametric spectrum 是唯一活动的真值事件生成器。

### 2.2 当前真正的阻塞项

现有 DT5790 数据只足以证明部分 run 存在脉冲样信号，尚不足以支持正式标定或残差学习：

- 15 个 `run3_X` 目录中，11 个含脉冲样信号、4 个为空；
- 相邻采样严格成对重复，`sampleTime=4000` 与导出数组的物理时间轴尚未确认；
- 多条记录存在振铃、台阶、低幅值、饱和或下降沿截断；
- 每个计数率目前只有一个 run，不能进行同工况独立 train/validation/test 划分；
- 能量字段是 ADC channel，不能当作已验证的 keV 刻度；
- 采集软件给出的粒子标签尚未被独立验证为 He-3 中子分类真值。

因此，当前项目在工程上已进入 Phase 6 入口审查，但科学上仍停留在“数据资格确认之前”。在这些问题
解决前直接训练网络 C，会产生数据泄漏、错误时间常数和不可复现的伪配对标签。

## 3. 数字孪生的边界与定义

### 3.1 孪生对象

孪生对象是**一条 He-3 比例计数器—前置放大器—数字化—触发链路**，不是整个核反应堆。

当前允许的外部输入：

- 死时间前真实计数率或分段计数率曲线；
- 探测器、气体、偏置、前放、采样、ADC、触发和死时间配置；
- 参数状态、采集 run、环境和设备版本元数据；
- 新的示波器/采集波形，用于校准和孪生状态更新。

当前输出：

- 真值事件账本及 marks；
- 连续模拟电压、裁剪前诊断电压、ADC 波形；
- 触发、死时间、饱和及观测事件；
- 波形特征、PSD、计数损失、模型差异和不确定度；
- 当前孪生状态、参数来源、适用域和漂移告警。

若未来加入反应堆功率、通量输运或点堆动力学到探测器计数率的映射，才可上升为“反应堆监测数字孪生
的一部分”。在此之前，论文和界面统一使用 `detector-channel digital twin` 或“探测器通道数字孪生”。

### 3.2 孪生闭环

孪生必须具有版本化闭环，而不只是一次性仿真：

1. **初始化**：从设备配置、文献范围和 `synthetic_demo` 基线建立先验；
2. **标定**：由合格的孤立脉冲和连续 run 估计参数分布及不确定度；
3. **预测**：对给定计数率和采集设置生成真值层、波形层和观测层；
4. **对齐**：将实测和模拟按 run、时间轴、极性、单位及触发条件对齐；
5. **差异评估**：比较事件统计、脉冲特征、PSD、堆积、饱和和死时间损失；
6. **受控更新**：仅在通过 QC 和留出验证后更新参数后验或残差模型；
7. **监测**：新 run 超出训练域、误差阈值或不确定度覆盖失效时触发漂移告警，不自动晋升为
   `validated`。

## 4. 优化后的总体架构

### 4.1 物理主链保持为唯一真值来源

物理主链继续采用三层契约：

1. **真值层**：计数率过程、He-3 反应沉积能量和事件 marks；
2. **连续信号层**：所有真值事件经过脉冲核、电子学响应、噪声和基线后的连续叠加；
3. **观测层**：裁剪、ADC、阈值、触发和死时间产生的可记录事件。

死时间只能改变观测层；网络也不得删除、移动或添加真值事件。真值事件账本和随机 seed 始终由物理链
维护，神经网络没有写权限。

### 4.2 物理模型由固定值升级为可校准概率模型

建议将现有固定参数逐步升级为带来源和不确定度的层次化参数：

- run 级：基线、噪声幅度、漂移、增益、小幅时间偏移；
- 工况级：计数率、偏置、高压、温度或采集设置的条件效应；
- 设备级：脉冲时间常数、能量到幅值关系、ADC、触发和死时间；
- 事件级：幅值、上升/下降时间、电荷和 wall-effect 类别的联合分布。

首版不必立即引入复杂贝叶斯平台。可以使用约束最小二乘/极大似然、按 run bootstrap 和层次化重采样，
先得到可复现的区间估计；数据量充分后再比较贝叶斯后验或似然自由推断。关键是每个参数都保存估计
方法、样本范围、置信区间、数据哈希、代码版本和 `provisional/validated` 状态。

### 4.3 神经网络 C：受物理约束的异方差残差模型

建议网络 C 使用轻量 1D dilated TCN，输入为：

- 校准后的物理波形；
- 事件锚点/事件掩码；
- `log10(rate)`、采样率和设备配置编码；
- 可选基线与噪声统计。

输出不直接替换波形，而是预测残差分布：

$$
y(t)=y_{\mathrm{phys}}(t)+\mu_r(t)+\sigma_r(t)\epsilon(t),
\qquad \epsilon(t)\sim\mathcal{N}(0,1)
$$

其中 `mu_r` 学习系统性偏差，`sigma_r` 表示条件异方差。模型必须采用小网络、显式残差幅值边界和
适用域检测。损失函数建议包含：

- 时域 Huber/L1；
- 多分辨率 STFT 和无事件区 PSD；
- 平均脉冲形状与电荷分布；
- 事件时间/计数保持；
- 残差能量和过度修正正则；
- 不确定度负对数似然与覆盖率校准项。

“物理约束”不能只写在损失函数里。推理后还必须执行验收投影/拒绝规则：若候选波形造成事件锚点
漂移超限、无依据新增触发、计数统计越界或残差幅值超出训练域，则回退到纯物理输出并记录拒绝原因。

### 4.4 网络 A 的退役方式

网络 A 标记为 `retired_by_user`。删除活动实现和可执行入口，不保留 B5，不允许未来网络 C 依赖其
事件输出。历史阶段文档、状态记录和忽略目录中的旧报告可保留用于审计，但不再构成软件能力或论文基线。

### 4.5 软件模块建议

后续阶段可新增而不破坏已验收接口：

```text
src/he3sim/
  calibration/
    profiles.py          # 厂商无关导入 profile
    quality.py           # 逐事件和 run 级 QC
    alignment.py         # 时间轴、极性、单位和触发对齐
    pulse_fit.py         # 双指数/模板拟合与不确定度
    parameter_model.py   # run/工况/设备层参数分布
  twin/
    state.py             # 孪生版本、参数后验和适用域
    update.py            # 受控更新与人工审批
    discrepancy.py       # 实测—预测差异和漂移告警
  ml/
    residual_model.py    # TCN + FiLM + 异方差输出
    residual_data.py     # 按 run 划分的伪配对 patch
    residual_training.py
    residual_evaluation.py
  analysis/
    paper_validation.py  # 统一论文实验、CI、消融和表格
```

Phase 1 的最小 HDF5 合同必须保持不变。孪生状态、标定后验和不确定度只加入新的完整数据集版本，建议
使用 `/calibration`、`/twin_state`、`/uncertainty` 和 `/provenance` 分组，并用 schema version 管理兼容性。

## 5. 实测数据与标定方案

### 5.1 数据资格门禁

任何实测 run 进入标定或训练前必须满足：

- 原始文件只读并保存内容哈希；
- 明确采样间隔、时间单位、电压单位、极性和 ADC 定义；
- 解释相邻重复样本来自导出复制、固件上采样还是有效采样；
- 保存设备序列、固件/软件版本、量程、阈值、高压、前放和环境信息；
- 逐事件 QC 至少包含 `tail_truncated`、`ringing`、`baseline_unstable`、`low_amplitude`、
  `saturation`、`duplicate_samples`、`trigger_clipped`；
- 粒子类别若无外部真值，只标记为 `unknown/candidate`，不能由采集软件标签自动变成已验证中子标签；
- train/validation/test 按 acquisition run 划分，禁止同一 run 的相邻窗口跨集合。

### 5.2 建议采集矩阵

| 数据类型 | 目的 | 最低建议 |
|---|---|---|
| 电子学脉冲发生器/已知频率信号 | 确认采样轴、重复点、ADC 和死时间 | 每种采样设置至少 3 个独立 run |
| 无源/背景 run | 基线、噪声、漂移、伪触发 | 每次采集会话前后各 1 个 run |
| 低计数率孤立脉冲 | 脉冲核、幅值、时间常数和模板 | 多于 1000 个通过 QC 的脉冲，来自至少 5 个 run |
| 多计数率连续波形 | 堆积、触发、死时间和残差模型 | 每个目标计数率至少 3 个独立 run；推荐 5 个 |
| 重复会话/跨日数据 | 漂移、适用域和孪生更新 | 至少 3 个独立会话 |
| 饱和/强堆积压力工况 | 失效边界 | 单独报告，不与普通工况混合 |

标准计数率仍采用 `10, 30, 100, 300, 1e3, 3e3, 1e4, 3e4, 1e5, 3e5, 1e6, 3e6,
1e7 cps`。若设备或源无法覆盖上限，只能声明“在实测上限内验证”，更高区间作为合成压力测试，不能
写成实测验证。

### 5.3 标定顺序

1. 用已知频率/脉冲发生器确认时间轴、ADC 和触发；
2. 用背景 run 估计基线、噪声、漂移和伪触发；
3. 用低计数率孤立脉冲拟合脉冲核和幅值联合分布；
4. 用中计数率连续波形拟合堆积下的电子学偏差与触发；
5. 用高计数率数据只验证饱和、恢复和死时间适用范围；
6. 由独立留出 run 复核，之后参数仍先标记 `provisional`，等待人工确认。

## 6. 论文实验设计

### 6.1 可证伪假设

- **H1（物理有效性）**：校准后的物理链能够在留出 run 上复现实测计数、死时间损失、平均脉冲和
  主要波形统计，并给出误差区间。
- **H2（残差价值）**：`physics + constrained C` 相对纯物理基线，在留出 run 和留出计数率上降低
  波形/PSD/特征联合距离，同时不破坏事件时间、计数和观测统计。
- **H3（约束价值）**：受约束网络相对无约束 TCN 具有更少的伪触发、事件漂移和域外失效。
- **H4（孪生更新价值）**：用新会话更新少量校准状态，可改善跨日漂移下的预测，并保持不确定度覆盖。

### 6.2 必须比较的基线

| 编号 | 链路 | 作用 |
|---|---|---|
| B0 | 未校准物理模型 | 展示标定的必要性 |
| B1 | 校准物理模型 | 主要可解释基线 |
| B2 | 校准物理 + 经验模板重采样 | 非神经网络数据驱动基线 |
| B3 | 校准物理 + 无约束 TCN | 证明物理约束是否必要 |
| B4 | 校准物理 + 受约束异方差 TCN | 推荐主模型 |

### 6.3 评价指标

**事件与计数：** 计数率偏差、Fano factor、间隔 KS/energy distance、间隔自相关、事件时间偏移、
伪新增/遗漏事件、触发率、延长/非延长死时间关系。

**能谱与脉冲：** 事件类型比例、能量/幅值/电荷/上升/下降时间边缘分布、联合 Wasserstein 或 MMD、
平均脉冲形状和置信带。

**连续波形：** 归一化 RMSE、残差自相关、多个频段的对数 PSD 误差、多分辨率 STFT 距离、基线与
噪声分布、饱和比例、堆积区和非堆积区分层结果。

**孪生与不确定度：** 50%/90% 预测区间覆盖率、区间宽度、校准误差、域外检测召回、跨会话更新前后
误差、参数漂移量和回退率。

**工程性能：** events/s、samples/s、CPU/GPU 时间、峰值内存/显存、HDF5 大小和可复现 seed。

### 6.4 统计设计

- 所有主结果以 acquisition run 为独立统计单位，不把相邻 patch 当独立实验；
- 使用按 run 分层 bootstrap 给出 95% 置信区间；
- 主模型与基线使用同一留出 run 的配对比较，同时报告效应量和区间；
- 低、中、高计数率、堆积、饱和和不同会话分别报告，不只给总体平均；
- 阈值必须在试验前写入配置并冻结，不能根据最终测试集反复调整；
- 完整测试集只在模型和阈值冻结后运行一次；失败案例全部保留。

### 6.5 建议预注册的验收原则

具体数值需由 pilot 数据确定并人工冻结，不能直接当成已验证门槛。建议至少包含：

- 主模型在留出 run 上的核心综合距离相对 B1 有稳定、置信区间不跨零的改善；
- 不允许通过牺牲事件计数、时间或触发统计换取视觉 RMSE 改善；
- 强堆积和饱和工况必须单独通过或明确标为适用域外；
- 90% 预测区间覆盖率应接近名义值，并同时限制区间不能无限变宽；
- 域外工况优先回退到 B1，而不是强行给出神经网络结果；
- 真值事件继续只由精确物理链生成，不重新启用已退役网络 A。

## 7. 优化后的阶段目标

现有 Phase 0～3 和 Phase 5 的历史验收不重写；Phase 5 另记为 `retired_by_user`。后续每次只执行一个
阶段，自动验收后停止等待人工审核。

| 后续阶段 | 目标 | 关键产物 | 出口门禁 |
|---|---|---|---|
| Phase 3.5-R | 完成本地 Web 人工复核 | 审核记录；不改物理模型 | 用户明确确认通过 |
| Phase 4Q | 数据资格与采样轴确认 | 只读清单、逐事件 QC、采样轴实验、run 划分清单 | 重复样本原因明确；可用 run 足以独立划分 |
| Phase 4C | 物理参数标定与不确定度 | 导入 profile、拟合、bootstrap/后验、`provisional` YAML、报告 | 合成回收通过；留出 run 拟合通过；人工确认 |
| Phase 4V | 校准物理孪生基线验证 | 多计数率 B1 报告、适用域与失败案例 | 事件/波形/死时间指标在预注册门槛内 |
| Phase 6S | 合成工程预演 | 人工干扰、事件保护TCN、模型卡、回退测试 | 仅synthetic_scaffold，不解锁正式路线 |
| Phase 6A | 伪配对残差 TCN 基线 | B2/B3/B4、模型卡、训练与留出评估 | B4 优于 B1/B3 且事件约束不退化 |
| Phase 6B | 不确定度、域外检测与孪生更新 | 异方差/ensemble、覆盖率、漂移告警、回退策略 | 跨会话留出有效；覆盖与回退达标 |
| Phase 7 | 论文级 V&V 与复现包 | 冻结配置、消融、统计表图、数据字典、稿件 | 独立复跑成功；所有结论可追溯 |

当前科学出口仍是 **Phase 4Q**，不是正式网络 C。Phase 6S已按比赛进度完成合成工程预演，但不能作为
入口替代。若无法新增独立run，Phase 4Q只能输出数据缺口和采集计划，不能以切分同一run绕过门禁。

## 8. 论文方案

### 8.1 推荐题目

中文：

> 宽计数率条件下 He-3 中子探测器通道的物理约束数字孪生：随机事件、电子学响应、残差学习与
> 不确定度验证

英文：

> **A Physics-Constrained Digital Twin of a He-3 Neutron Detector Channel Across Wide Count-Rate
> Regimes: Stochastic Events, Electronics Response, Residual Learning, and Uncertainty Validation**

若最终没有跨计数率独立实测数据，不要使用 “across wide count-rate regimes” 或 “validated” 字样，
应降级为 calibration framework / feasibility study。

### 8.2 预期创新点

1. 保持真值事件、连续波形和观测事件严格分层的宽计数率 He-3 探测器通道孪生；
2. 将可解释泊松/能谱/电子学模型与受约束残差学习结合，而非用黑箱替代物理；
3. 按 run 留出、跨计数率/跨会话验证及显式不确定度和适用域；
4. 在同一框架中统一评价堆积、饱和、触发和死时间，并提供可复现 HDF5 数据契约；
5. 用精确事件账本与受约束残差网络的职责分离避免黑箱改写计数统计。

### 8.3 推荐图表

1. 三层物理链与数字孪生更新闭环；
2. 数据采集、QC、run 划分和伪配对流程；
3. 低/中/高计数率下实测与 B1/B4 代表波形及残差；
4. 各计数率的计数偏差、PSD/STFT 距离和触发/死时间误差；
5. 受约束与无约束网络的事件保持/伪触发比较；
6. 不确定度可靠性图与跨会话漂移更新；
7. 失败案例、饱和与适用域边界；
8. 精度—速度—资源对比表及完整消融表。

### 8.4 期刊路径

- **首选 `Nuclear Engineering and Technology`**：当前问题同时覆盖 Nuclear I&C、辐射测量、堆积/
  死时间和核工程数字孪生，主题匹配度最高。
- **备选 `Nuclear Instruments and Methods in Physics Research A`**：若文章重点放在 He-3 探测器、
  前放信号、DAQ、PSD 和实测对比，且实验细节充分，此方向更合适。
- **条件性备选 `Annals of Nuclear Energy`**：只有在后续明确加入反应堆功率/通量—计数率映射、
  监测用例或状态估计，形成清晰的核能系统联系后再考虑。

### 8.5 论文结构

1. Introduction：核反应堆中子监测、He-3 信号、堆积/死时间和现有黑箱生成的不足；
2. Detector-channel twin definition：孪生对象、三层状态、更新闭环和适用域；
3. Physics model：到达、能谱、脉冲、连续叠加、ADC、触发和死时间；
4. Calibration and uncertainty：数据资格、run 级划分、参数估计和不确定度；
5. Physics-constrained residual model：TCN、条件、损失、拒绝/回退；
6. Experimental design：数据、基线、计数率、指标和统计方案；
7. Results：物理基线、残差价值、约束消融、跨计数率/会话、不确定度和性能；
8. Discussion：已退役事件网络、失效边界、数字孪生层级和安全含义；
9. Conclusion：只陈述实验证据支持的范围。

## 9. 风险控制

- **数字孪生概念过度包装**：必须存在数据对齐、版本化更新、不确定度和漂移监测；否则只称模拟器。
- **实测标签不可信**：没有外部真值时不研究分类准确率，只研究波形一致性和候选事件。
- **同一 run 数据泄漏**：强制 run 级划分，patch 只能继承所属 run 的 split。
- **采样轴错误**：在时间常数、STFT 或残差标签计算前用独立信号确认采样轴。
- **网络学习触发/截断伪影**：QC 分层，保留原始版本字段，截断数据不用于完整脉冲残差目标。
- **物理模型过简**：通过模板基线、恢复模型和失败案例判断是否需要扩展，不直接用更大网络遮盖问题。
- **高计数率不可实测**：明确区分“实测验证范围”和“合成压力测试范围”。
- **不确定度虚假**：同时检查覆盖率与区间宽度，并在域外回退。
- **论文只剩软件介绍**：主结论必须来自独立实测 run、预注册比较和统计区间。

## 10. 近期优先级

1. 关闭或明确记录 Phase 3.5 人工审核状态；
2. 执行 Phase 4Q，只做数据资格、采样轴确认和采集缺口；
3. 新采集至少三个独立 run/计数率，优先保证低、中、高三档和跨会话，而不是先追求所有 13 点；
4. 冻结论文 protocol：研究假设、split、基线、指标和测试集使用规则；
5. 完成 Phase 4C/4V 后，才开始 Phase 6A；
6. 只有 Phase 6A 在留出 run 上展示净增益，才实施 Phase 6B；
7. 所有 `synthetic_demo`、`provisional` 和 `validated` 状态继续写入配置、产物和论文表格。

## 11. 主要文献依据

- Langford 等的 He-3 比例计数器研究表明，上升时间与脉冲高度的联合信息可用于事件识别和背景抑制，
  支持本方案保留脉冲时间特征与二维联合评价：
  <https://www.nist.gov/publications/event-identification-he-3-proportional-counters-using-risetime-discrimination>
- Beltran 等建立了从 He-3 俘获到信号处理电子学的详细比例计数器 Monte Carlo，说明探测器与电子学
  联合建模是合理的物理基线：<https://arxiv.org/abs/1104.2573>
- Usman 与 Patil 综述指出延长型和非延长型死时间的适用性依赖实际工况，支持本方案把死时间模型作为
  需实测验证的观测层，而不是固定真理：<https://doi.org/10.1016/j.net.2018.06.014>
- 高伽马场 He-3 研究显示堆积会削弱单纯脉冲高度判别，而上升时间/高度联合特征可改善判别，支持宽
  计数率下分层报告堆积和触发统计：<https://doi.org/10.1016/j.net.2018.08.013>
- 核反应堆数字孪生的 PINN 工作强调物理模型和数据模型的混合、插值/外推评价及外推精度下降问题，
  支持本方案的物理主链、适用域和回退设计：<https://doi.org/10.3390/en15207697>
- INL 关于核数字孪生传感器、仪控与通信集成的工作把数据质量和不确定度视为关键缺口，支持先执行
  数据资格门禁：<https://www.osti.gov/biblio/2000352>
- 2026 年微堆保障数字孪生研究使用代理模型并显式评估传感器不确定度和检测概率，进一步支持把 UQ
  作为孪生主功能而非附录：<https://doi.org/10.1016/j.anucene.2026.112412>

## 12. 结论

项目的最优路线不是继续堆叠更大的生成网络，而是把现有稳定物理模拟器升级为**可校准、可更新、
带不确定度和适用域的 He-3 探测器通道数字孪生**。首篇论文的成功取决于 Phase 4Q 的数据资格、独立
run 采集和 Phase 4C/4V 的物理基线，而不是 Phase 6 网络规模。网络 C 只有在严格留出实验中改善实测
一致性且不破坏核计数统计时，才构成可信的论文创新。
